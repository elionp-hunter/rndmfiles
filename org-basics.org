* Motion(lol)
** movement : same as vim(hjkl)
** next/prev heading: gj/gk OR CTR-j/k
** move parent/child element : gh/gl

* Structure Editing
** insert new heading after subtree: CTRL - RET
** promote/demote heading: M-h/l
** promote/demote current subtree : M-Shift-h/l
** move subtree/list item up/down : M-j/k
** move list item up/down but not subtree : M-Shift-j/k

* Evil mode binds
** select an element : var
** selent an element : dae
** select a subtree : vaR
** delete subtree : daR
** yank subtree: yiR
