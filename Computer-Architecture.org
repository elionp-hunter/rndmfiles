* REVIEW
** Basic Questions
*** What is a program?
- A program is a sequence of instructions writtern for the CPU to execute.
*** What is data?
- Data is the information the program operates on.
*** What does it mean to run the program?
- Running a program means executing its instructions one by one on the CPU.
*** What computer component executes programs?
- CPU (Central Processing Unit).
*** Where is the running program stored? What else (other that the program code) is stored there?
- Stored in RAM
- RAM also stores data, stack, heap, variables, and intermediate results.
*** What do we know about RAM memory?
- Random-access (you can reach any cell directly).
- Volatile (loses contents when power is off).
- Slower than the CPU cache.
*** What is memory stall?
- When the cpu has to wait because data/instructions aren't ready from RAM.
*** What long-term storage do we have?
- Hard drives(HDD), solid state drives(SSD),optical discs, flash memory.
*** What is a executable file?
- A binary file containing machine code instructions that the CPU can execute directly.
*** How speed of CPU, RAM and hard disk compare to each other?
- CPU > RAM > DISK => fastest to slowest
- CPU works in nanoseconds, RAM in tens/hundreds on ns, storage in ms.
*** What is cache memory? What is it's purpose?
- Small, very fast memory(RAM) inside/near the CPU.
- Stores frequently used instructions/data to reduce memory stall. Doesn't have to read for RAM again.
*** What is ROM memory? What does it store?
- Read-only memory.
- Stores firmware/BIOS - permanent startup instructions for the computer.
*** What is machine cycle?
- The basic process the CPU follows to execute instructions.
*** What are the basic steps of machine cycle?
- Fetch -> Decode -> Execute -> Write-Back.
*** What does frequency measure? What is the measurement unit of frequency?
- Measures how many cycles per second occur.
- Unit: Hertz (Hz = cycles/second).
*** What is CPU clock? What is CPU frequency?
- CPU clock: the timing signal that drives the CPU's operations.
- CPU frequency: how many cycles per second the clock ticks (GHz range).
*** What is CPU core? What does it mean "quad-core CPU", "octa-core CPU"?
- A core is an independent processing unit inside a CPU.
- How many cores means how many tasks in can run in parallel.
*** What does memory look like?
- As a linear array of bytes, each with a unique address.
*** What is a byte? What is a bit? How many bits are in a byte?
- Bit: smallest unit, 0 or 1.
- Byte: 8 bits.
*** What is memory address?
- A unique number assigned to each byte in memory.
*** What is the momory address of a larger chunk of memory?
- It's the address of the first byte in that chunk.
*** What is the length of memory address? What does it mean "32-bit address"?
- The number of bits used for addresses.
- Means the address is 32-bits long
*** How much memory can we address/use with the given length of memory address?
- With n-bit address -> 2^n bytes of addressable memory.
- Ex: 32-bit -> 2^32 = 4GB max.
*** How long should memory addresses be to address a given amount of memory?
- Solve log_2 (memory size in bytes).
- Example: 1TB needs log_2(2^40) = 40-bit addresses.
*** Can memory contain nothing at all?
- No, every cell holds some binary value (even if it's meaningless/unused).
*** What is the relationship between C++ variable, RAM and memory address?
- A variable is stored in RAM.
- Each variable occupies memory at a specific address.
*** What is a C++ pointer?
- A variable that stores the memory address of another variable.
*** What is the most common size of the following C++ data types? Does signed/unsigned affect those sizes?
- Char: 1 byte
- Short: 2 bytes
- int: 4 bytes
- long: 4 or 8 bytes (depends on system)
- long long: 8 bytes
- float: 4 bytes
- double: 8 bytes
- signed/unsigned does not change the size, only the bits are interpreted.
*** Hexadecimal numbers. Why do we use them? How to convert from hexadecimal to binary and back quickly?
- Hex is a compact way to represent binary.
- Each hex digit is 4 bits.
- Conversion 1 hex digit <-> 4-bit binary group.
*** What is a "word"?
- Natural data size of the CPU(32 or 64-bit).
*** What is a PC?
- Program Counter: CPU register holding the address of the next instruction to fetch.
*** What is the language that the CPU understands?
- Machine language (binary machine code).
*** How can we execute program written in higher-level languages?
- It must be translated into machine code (via compiler or interpreter).
*** What is a compiler? What are compiler advatages?
- Compiler: Translates entire high-level program into machine code before execution.
- Advantages: Fast, error checking before run, optimized code.
*** What is an interpreter? What are interpreter advantages?
- Interpreter: translates and executes program line by line at runtime.
- Advantages are easier debugging, platform independence, no need to compile before running.

***** EXAMPLE PROBLEM (p34)

Our favorite program runs in 10 seconds on computer A, which has a 2GHz clock. We are trying to help a computer designer build a computer B, which will run this program in 6 seconds. The desinger has determined that a substantial increase in the clock rate is possible, but the increase will affect the rest of the CPU design, causing computer B to require 1.2 times as many clock cycles as computer A for this program. What clock rate should we tell the designer to target?

Execution Time : 10 seconds
Clock Rate = 2GHZ = 2 M cycles/second

Number of Clock Cycles = Execution x Clock Rate
Num CC (A) = 10 s x (2 x 10^9) = 20 x 10^9

Target time B = 6 seconds

Number of CC (B) = 1.2 (20 x 10^9)
Number of CC (B) = 24  x 10^9

The program would take 24 billion clock cycles on computer B

DO TABLE ON TEST

To reiterate:
 - Clock Rate (A) 2GHZ ,  (B)
 - CPU Time   (A) 10s  ,  (B)  6s
 - Total Clock Cycles (A) 20 x 10^9 ,  (B)  24 x 10^9
 - Frequency B = 24 x 10^9 / 6s = 4 x 10^9 = 4GHz
